# WordToHtml

把一份「一行一段的类 md 文本」编译成 **A4 分页预览** 与 **Word 可继续编辑的 docx**；
也可以直接在 A4 版面上写（所见即所得），改完同样导得出 docx。
页面够宽时自动两页并排，打印与导出的仍是「一页一张纸」。

面向中文正式公文（情况说明、报告、立场文件）：字体、字号、行距、段距、编号规则全按一张固定规格表来，
不必自己调排版参数。

> 要改代码 / 二次开发请看 [`PLAN.md`](PLAN.md) —— 组件接口、文件地图、验收脚本、还开着的问题都在那里。

## 快速开始

```bash
npm install
npm run dev
```

终端会给出本地地址（默认 <http://localhost:5173>）。打开后左右分栏：**左边写内容，右边即时出 A4 版面**。

顶栏那一行是**文件名**，可以直接改 —— 导出 docx 用的名字就是它加 `.docx`（空着兜底成「未命名.docx」）。
两种写法，用顶栏的「所见即所得 / 类 md 源码」切换：

- **所见即所得**（默认）：直接在纸上打字；加粗、改色、插表格、加批注都在版面上做；
- **类 md 源码**：在左侧文本框里按下一节的语法写纯文本，右侧即时看到版面。

写完可以：`Ctrl+P` 打印（只出 A4 纸，屏幕上的工具栏与源码栏都会被隐掉），或点「导出 docx」。
用 Word 打开导出的 docx，样式名与 Word 内置样式（标题／标题 1…）对得上，可以接着编辑。
「保存」（或 `Ctrl+S`）把当前内容按源码语法回吐成一段文本，方便存档或交给别的程序。

## 源码语法

一个非空行就是一段（**行与行不会合并成同一段** —— 公文习惯是一行一段，用空行分隔反而要多敲回车）。
空行只起分隔作用，不产出内容。

| 行首标记 | 含义 |
| --- | --- |
| `# 标题` | 文本标题（华文中宋 18pt 加粗居中） |
| `## 标题` | 一级标题，自动编号 `一、` |
| `### 标题` | 二级标题，自动编号 `（一）` |
| `#### 标题` | 三级标题，自动编号 `1、` |
| `@ 抬头` | 抬头（正文但取消首行缩进） |
| `>> 落款` | 落款（正文但右对齐），连续多行成组 |
| `% 附件` | 附件标记（黑体、顶格、段后一行） |
| `- 条目` | 列表段落（五号 10.5pt，无段前段后） |
| `! 条目` | 列表标题（五号加粗居中） |
| `---`（独占一行） | 分节符：新起一页，页码从 1 重排 |
| `===`（独占一行） | 分页符：只强制换页，页码连续 |
| `:::table … :::` | 表格围栏块，见下 |

括号里的字体字号是**「管理人文件」模板**（默认）的值。切到「简易公文格式」后整篇按那套排：
正文与各级标题三号 16pt 仿宋、标题二号 22pt 方正小标宋简体、列表与页脚四号 14pt、行高 28.95pt，
三级标题（`####`）的编号也从 `1、` 变成 `1. `（详见下面的「文件模板」一节）。

文档**最前面**还可以有两行指令（写在正文之前，谁先谁后都行；正文里出现的这两行按普通文字处理）：

| 行首标记 | 含义 |
| --- | --- |
| `::editor …` | 编辑器开关：`trackChanges=on`、`nav=off`。**只写非默认值**（默认 = 修订关、导航开） |
| `::section …` | 首节的设置：`numbers=off` / `restart=on` / `orientation=landscape`（同样只写非默认值） |

`::editor` 只表示「打开文件时，界面上的修订模式与导航窗格该是什么状态」，**不进 docx**。

```
::editor trackChanges=on
::section numbers=off

# 标题
……
```

分节符 `---` 后面也可以跟同样的 kwargs，用来描述**它开启的那一节**（例如 `--- link=off restart=on`：
这一节独立设页脚、页码从 1 重排）。什么都不写就是全默认 —— 新节关联前节、页码接着往下数。

### 表格

表格用一段围栏块包起来，首行是 `:::table`（可带 `minLines=1|2`、`cantSplit=yes|no` 两个参数，
只写非默认值：`minLines` 默认 1、`cantSplit` 默认 true），末行是独占一行的 `:::`：

```
:::table minLines=2
> 单位：元
| 项目 | 金额 |
| 甲 | 1,234.00 |
< 注：以上金额不含税
:::
```

- `>` 开头是**表头行**（「单位：元」这类文字）、`<` 开头是**附注行**，两者**整行一格**、无边框，
  分别右对齐／左对齐；`|` 开头是**数据行**。
- 表内每行**按未被转义的 `|` 切格**，所以格子里要有竖线就写 `\|`，要有反斜杠就写 `\\`；
  每格的文字走同一套行内语法（`**加粗**`、`__下划线__`、`{红|…}`、`{+…}`、`{-…}`、`[[…|批注]]`）。
- **格内可以分段**（对应 Word 里一个单元格放多个段落）：一段之内写 `{p}` 就是另起一段，
  例：`| 甲资产{p}（已抵押） | 1,234.00 |`。`{p}` 只在表格格里是语法，正文里它只是普通文字。
- **行高**两档就是 `minLines`：1 = 最小一行、2 = 最小两行（内容更多就自己撑高，没有上限）。
  它只管数据行 —— **表头行与附注行恒为一行高**；**一格里的各段一起算高度**（格内三段就至少要三行）。
- `cantSplit` 默认禁止本行跨页断开；表格总宽固定占满版心宽（页面宽减去左右页边距），列宽等分。
- **格首指令**：一格的内容可以整格包在 `{@<token>[,<token>]…|<格内正文>}` 里，用来逐格换样式与对齐：
  样式名（`title`/`h1`/`h2`/`h3`/`body`/`salutation`/`signature`/`attachment`/`listTitle`/`listItem`，
  缺省 `listItem`）、水平（`left`/`center`/`right`）、垂直（`top`/`middle`/`bottom`，缺省 `top`）。
  只写非默认值，顺序固定「样式 → 水平 → 垂直」。例：`| {@h2,center|项目} | {@center|金额} |`。

行内标记（可互相嵌套）：

| 写法 | 含义 |
| --- | --- |
| `**文字**` | 加粗 |
| `__文字__` | 下划线 |
| `{红｜文字}` | 改色，支持中文色名（红黑蓝绿紫橙灰黄白）或 `{#RRGGBB｜文字}` |
| `{+文字}` | 插入修订 |
| `{-文字}` | 删除修订 |
| `[[文字｜批注内容]]` | 批注，锚定在「文字」上 |
| `{br}` | 软换行（零宽、不占字符位；`Shift+Enter` 打出来，正文段落与表格格子里都能用） |
| `\` | 转义上述标记字符 |

> 上表里的全角竖线是为了在文档里显示清楚，实际语法用的是**半角 `|`**。

## 在版面上编辑

打字、输入法组字、选区、剪贴板都交给浏览器，手感是原生的；而**结构性操作改的是模型**，
所以界面上改的和导出 docx 用的永远是同一份内容，不会出现「界面改了、导出没改」。

- **回车分段**：在插入符处切开当前段落；当前是标题类段落时，后半段成为正文段。
- **`Shift+Enter` 软换行**：在段落内换一行（不断段，对应 Word 的 `<w:br/>`）。换行落在段尾时，
  那一行是空行 —— 与 Word 一样，段落因此多占一行。
- **退格合并**：插入符在段落最前面且没有选区时，退格 = 与上一段合并；段尾 Delete = 把下一段接上来。
- **跨页也能删**：页尾 Delete／页首 Backspace 删的是相邻页上的那一个字（每页是独立的一页纸，
  浏览器原生删不过页边界，这一步由程序接管）。
- **选中跨段的一段再删**：按 Word 语义接起来 —— 段落标记被删掉、两头并成一段，中间整段消失。
  只有选区里夹着**表格格子**时才退回「各自删掉选中的文字」（段落标记的合并／切开只对正文段落有意义）。
- **粘贴**按纯文本处理，换行还原成新段落（不导入外部 HTML 的样式）。
- **修订模式**（`Ctrl+Shift+E` 或顶栏开关）：新增文字标插入、删除不真删（原地留痕），与 Word 一致。
  选中修订文字后点「接受修订／拒绝修订」收尾；没选中文字时按插入符所在的那一串算。
- **批注**：选中文字 → 在「插入」页写内容 → 添加。文档里有批注时右侧自动出现审阅栏
  （锚定文字 + 作者 + 时间 + 内容 + 回复），点条目会在正文里高亮并滚过去。
- **撤销重做**走组件自己维护的栈（`Ctrl+Z` / `Ctrl+Y`，深度 200），与浏览器菜单里的「撤销」不是同一套。
- **查找替换**（`Ctrl+F` 查找／`Ctrl+G` 替换）：预览区右上角浮出一个小面板，拖标题栏可移动，
  `×` 或 `Esc` 关闭；`Enter` 下一个、`Shift+Enter` 上一个。面板里可勾「使用正则表达式」（默认不勾）、
  范围可选「全文」（默认）或「当前选中的文本」，并显示「第 n / 共 m 处」。
- **导航窗格**：文档里有标题时，编辑器最左侧出现一栏（可折叠），按层级列出三级标题的编号与文字；
  点一条就把那一段滚到屏幕中间。

### 表格里怎么操作

- 光标进格子就能直接打字；`Tab` / `Shift+Tab` 按**行优先**顺序跨格 ——
  **在最后一格按 `Tab`（或第一格按 `Shift+Tab`）不作任何响应**，不换行、也不自动加行。
- `←` / `→` 只在**格首**（←）或**格尾**（→）跨到上一格末尾／下一格开头；`↑` / `↓` 在格内首行／末行时跨格。
- 格内 **`Shift+Enter`** 插一枚软换行（同一段里换行）；格内 **`Enter` 在插入符处另起一段** ——
  一个格子里可以放多段（Word 的单元格本来就是这样），段距按各段样式逐段算。
- 格内的**段首 Backspace** 与上一段合并、**段尾 Delete** 把下一段接上来（都只在本格内，一步可撤销）；
  **第 0 段的段首退格与最后一段的段尾 Delete 不作任何响应** —— 放给浏览器的话原生会把相邻格子并掉，
  表格结构当场就坏。
- 「表格」页提供落点提示（第 N 行第 M 列）、增删行列、行高两档、表头行／附注行开关、
  水平与垂直两组对齐、以及最右端的**删除整表**（不二次确认，靠撤销兜底）。
- **复选多格**：在格内按下后**拖出起点格**就转成整格刷选（矩形块）；`Ctrl+点击`在原基础上**并**一块矩形，
  **`Ctrl+点击`一个已选中的格 = 去掉包含它的那一块**。`Esc` 或点正文别处即清空。
  批量能套用的只有「两组对齐」与「样式」；行高、表头／附注行开关、增删行列仍按**落点那一格**工作。
  一次批量只记一步撤销。

## 文件模板

顶栏的「文件模板」下拉把**样式与页边距绑成一体**整体切换（公文体例里页边距本身就是格式的一部分，
让人分别选「样式」和「页边距」只会拼出既不是甲也不是乙的东西）：

| 模板 | 样式 | 页边距 |
| --- | --- | --- |
| 管理人文件 | 华文中宋标题（18pt 加粗）＋仿宋正文（14pt，列表 10.5pt） | 四边 25mm |
| 简易公文格式 | 方正小标宋简体标题（22pt）＋三号 16pt 仿宋正文（一~三级标题分别为黑体／楷体／仿宋），列表与页脚四号 14pt | 上 37 / 下 35 / 左 28 / 右 26 mm |

「简易公文格式」按公文网格排：**每页 22 行**，行高固定 28.95pt（正好一个网格行高），正文与各级标题
都不留段前段后，标题下方空一行也是一个网格行高。**每行 27 字**，不是 GB/T 9704 写的 28 字 ——
版心宽 156mm、三号字每字 16pt，只放得下 27 字；Word 能做到 28 字靠的是文档网格压缩字符间距，
浏览器的排版引擎没有这个能力。想凑满 28 字得把左右边距各让 2mm（各 25mm、版心 160mm），
但那样版心就不是公文标准的 156×225mm 了，所以这里选择保版心。

切模板会整篇重新量测排版（版心宽高变了，页码自然跟着变）；插入符与选区不会丢。

## 打印与导出

打印样式（`Ctrl+P`）会把编辑器外壳全部隐藏，只留 A4 纸：纸的尺寸取自规格表，
纸上的白边由版心自己的页边距提供，一页一张纸 —— 打印预览里的页数与断页位置与屏幕上一致，
不会被裁掉后面几页，也不会多出空白页。

导出的 docx 与屏幕上的版面用同一份内容算出来，样式名与 Word 内置样式（标题／标题 1-3／正文／页脚）
逐字对得上，Word 里能接着改。

## 已知限制

- **字体依赖本机安装**。预览与 docx 写的是「仿宋／黑体／楷体／华文中宋／方正小标宋简体／Times New Roman」，
  都是商业字体、不能内置；换一台没装这些字体的机器，字形会回退（汉字字宽不变 —— 这些字体都是整 1em，
  一行几个字不受影响；西文混排的断行位置会变）。「简易公文格式」的标题要另装「方正小标宋简体」。
- **预览与 Word 是两套排版引擎**，逐页对齐只验到内置样本这一级（样本上两套模板的页数都与 Word 吻合）。
  换字体、混排西文比例很高、或超大表格时，两个引擎本来也可能出现逐行差异。
- **自动编号写成了正文文字**（不是 Word 原生多级列表）。好处是预览所见即所得、重新导入能准确还原；
  代价是在 Word 里手动增删标题不会自动重编号（在本编辑器里会自动重排）。
- **「段前／段后 N 行」是真实的行单位**（打包后补写 `w:beforeLines` / `w:afterLines`）：Word 里显示为
  「N 行」、随文档网格行高联动，预览按同一个网格基准（`page.gridLinePt`）折算成磅。
  一处固有约束：网格行高在 Word 里是**节属性**（`w:docGrid`），全篇只能有一个值。
- **分节符会在 Word 里多出一个空段落**（上一节末尾多一个空行）。
- **批注的「已解决」状态需要线程**：只有存在回复时 `docx` 才会写 `commentsExtended.xml`，
  因此单条批注标记「已解决」不生效（库的现状）。
- 预览里的批注高亮与修订着色是**近似**，不追求与 Word 像素级一致。
- **横竖混排的打印只验到规则层**：屏幕上的每页几何可断言，打印时的方向靠命名页表达；
  横排／混排真打出来的观感仍需人工核对。
- **查找替换**：替换文字按纯文本处理，**不支持 `$1` 这类反向引用**；**默认大小写敏感**，
  没有「忽略大小写」开关；正则的零宽匹配（如 `^`、`a*`）不进结果集；**已标记删除的文字不参与查找替换**
  （否则对同一处反复替换会不断叠加）。
- **导航窗格的大纲取自渲染快照**：刚敲进去、还没触发重排的标题文字，要等下一次分页才反映到左栏。
- **改绑快捷键不会「接管」浏览器的原生编辑键**：把加粗／下划线改到别的组合键之后，
  原来的 `Ctrl+B`／`Ctrl+U` 会落回浏览器的原生加粗／下划线 —— 结果照样同步进模型、导出不失真，
  但这一步不再经过本编辑器工具栏的语义；没有原生行为的动作（`Ctrl+Shift+E`、`Alt+4`）改绑后则彻底失效。
- **源码视图与版面之间来回切换会经过一次序列化**，修订的作者／时间戳与批注的回复关系在那条路上会丢
  —— 那个视图只做展示用，别拿它当存档。
- 一处**已知缺陷**（目前未修，也记在 `PLAN.md` 里）：
  「节」工具条的**控件**要光标落进正文才出现（外壳是常驻的）。
